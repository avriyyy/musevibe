# Fun-isometric loading sticker

The `fun.ts`, `motions.ts`, `icons.ts`, and `Sticker.tsx` files in this folder are copied from Kelvin Adithya's [fun-isometric skill](https://github.com/kelvinkn17/skills/tree/main/skills/fun-isometric). They power the animated folder shown during project preparation and prototype-page generation. The implementation follows the kit's After Effects-style keyframe presets and honors reduced-motion preferences; no extra runtime dependency is used.

`LoadingSticker.tsx` is MuseVibe's small wrapper: it pairs the kit's `folder` icon with the app's blue/green brand palette. See [`LICENSE`](./LICENSE) for the upstream MIT license.
