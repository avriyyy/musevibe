## Confirmed problems (from code + 5-area read-only audit)
1. `src/lib/ai.ts` silently converts every provider failure into local output; prototype local output is a generic placeholder that passes visibility checks and is saved as a real page.
2. `generatePage` has no catch; per-page errors are invisible, Generate all stops silently.
3. `mockGenerate('doc')` always labels docs as PRD; non-PRD local fallback is wrong.
4. `WorkspaceChat` reads `data.text` but `/api/ai/transcribe` returns `transcript`; voice input always says nothing heard.
5. Page path mismatch: prompt/nav/fallback use `slug.html`, files are `page-slug.html`; prototype links 404 and duplicate slugs collide.
6. Custom design-system showcase is `design-system.html` but sidebar filters id starting `ds-`, so it cannot be focused.
7. Wizard state can leak across `?id=` changes; stepper can jump to Review without required answers.
8. `/api/ai/generate` does not validate JSON/kind/prompt; unknown kind becomes PRD.
9. DocView preview can show stale markdown before 700ms debounce flush.
10. No project delete control; seeded demo opens empty and regenerates on open.
11. Design canvas zoom stack overlaps the neighboring frame; canvas opens with a neighbor peeking in.
